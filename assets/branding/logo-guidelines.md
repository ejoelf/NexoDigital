# Guía de uso del logo — NexoDigital

## Versiones incluidas

La identidad inicial incluye:

- Logo horizontal.
- Logo vertical.
- Isotipo.
- Monocromático negro.
- Monocromático blanco.
- Favicon.
- App icon.
- Avatar para redes.

## Área de seguridad

Mantener alrededor del logo un espacio mínimo equivalente al ancho del trazo principal del isotipo.

No colocar textos, bordes, iconos u otros elementos demasiado cerca del logo.

## Tamaño mínimo recomendado

- Logo horizontal digital: 160 px de ancho.
- Isotipo digital: 32 px de ancho.
- Favicon: 16 px mínimo, ideal 32 px o más.
- Impresión: 30 mm de ancho mínimo para logo completo.

## Usos correctos

- Logo azul/cian sobre fondo blanco o gris claro.
- Logo blanco sobre fondo grafito o azul oscuro.
- Isotipo solo para favicon, avatar, app icon, GitHub y espacios reducidos.
- Versión horizontal para encabezados, sitio web, propuestas y presentaciones.
- Versión vertical para piezas institucionales o composiciones centradas.

## Usos incorrectos

No hacer lo siguiente:

- Estirar o deformar el logo.
- Cambiar los colores oficiales sin criterio.
- Agregar sombras exageradas.
- Usar sobre fondos con bajo contraste.
- Rotar el isotipo.
- Encerrar el logo en formas no previstas.
- Usar el isotipo como patrón sin control visual.

## Personalidad visual

El logo debe sentirse:

- Tecnológico.
- Claro.
- Sólido.
- Premium.
- Cercano a pymes.
- Escalable para un ecosistema de SaaS.
