# Brand Kit Oficial — NexoDigital

Este directorio contiene la identidad visual oficial de **NexoDigital**.

NexoDigital es una empresa de transformación digital enfocada en software SaaS, páginas web, automatización, inteligencia artificial, CRM y soluciones tecnológicas para pymes.

## Concepto visual

La identidad de NexoDigital se construye sobre la idea de **nexo**: conexión, puente, ecosistema y transformación. El isotipo parte de una **N geométrica**, simple y tecnológica, formada por trazos modulares que representan unión entre negocios tradicionales y soluciones digitales.

## Usos principales

- Sitio web oficial.
- CRM y paneles internos.
- Redes sociales.
- Presentaciones comerciales.
- Propuestas para clientes.
- Firma de email.
- Favicon.
- GitHub.
- Aplicaciones SaaS del ecosistema NexoDigital.

## Archivos principales

- `logos/svg/nexodigital-logo-horizontal.svg`: logo principal horizontal.
- `logos/svg/nexodigital-isotipo.svg`: símbolo sin texto.
- `logos/svg/nexodigital-logo-vertical.svg`: versión vertical.
- `logos/svg/nexodigital-monochrome-black.svg`: versión monocromática negra.
- `logos/svg/nexodigital-monochrome-white.svg`: versión monocromática blanca.
- `logos/favicon/favicon.svg`: favicon SVG.
- `icons/app-icon.svg`: icono de aplicación.
- `social/avatar.svg`: avatar para redes sociales.
