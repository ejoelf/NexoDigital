# Tipografía — NexoDigital

## Tipografía principal recomendada

**Sora**

Sora es una tipografía sans serif moderna, geométrica y tecnológica. Funciona muy bien para marcas digitales, productos SaaS, dashboards, sitios web y presentaciones comerciales.

Uso recomendado:

- Logo / wordmark: Sora SemiBold o Bold.
- Títulos: Sora Bold.
- Subtítulos: Sora SemiBold.
- Texto de interfaz: Sora Regular o Medium.
- Botones y etiquetas: Sora Medium.

## Alternativas gratuitas

Si Sora no está disponible, usar:

1. **Inter**
2. **Manrope**
3. **Plus Jakarta Sans**
4. **DM Sans**

## Jerarquía recomendada para web

```css
--font-brand: 'Sora', 'Inter', system-ui, sans-serif;

h1 {
  font-size: clamp(2.4rem, 5vw, 4.5rem);
  font-weight: 700;
  letter-spacing: -0.04em;
}

h2 {
  font-size: clamp(1.8rem, 3vw, 3rem);
  font-weight: 700;
  letter-spacing: -0.035em;
}

body {
  font-size: 1rem;
  font-weight: 400;
  line-height: 1.6;
}
```
