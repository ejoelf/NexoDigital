# Mockups — NexoDigital

Carpeta destinada a aplicaciones visuales de marca.

## Mockups sugeridos

- Tarjetas personales.
- Notebook.
- Remera.
- Cartel de oficina.
- Sitio web.
- Pantalla de software / dashboard.
- Firma de email.
- Presentación comercial.

## Recomendación

Guardar los mockups en PNG o JPG optimizados para web y en PDF si se preparan para presentación comercial.

Naming sugerido:

```txt
mockup-business-card.png
mockup-notebook.png
mockup-tshirt.png
mockup-office-sign.png
mockup-website.png
mockup-dashboard.png
```
