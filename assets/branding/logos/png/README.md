# PNG — Logos NexoDigital

En esta carpeta se deben guardar las versiones exportadas en PNG.

## Tamaños recomendados

- `nexodigital-logo-horizontal@1x.png` — 1200 x 320 px.
- `nexodigital-logo-horizontal@2x.png` — 2400 x 640 px.
- `nexodigital-isotipo@1x.png` — 512 x 512 px.
- `nexodigital-isotipo@2x.png` — 1024 x 1024 px.
- `nexodigital-logo-vertical@1x.png` — 720 x 720 px.
- `nexodigital-avatar@1x.png` — 1080 x 1080 px.

## Exportación recomendada

Exportar desde los SVG ubicados en `assets/branding/logos/svg/`.

Usar fondo transparente salvo que el archivo indique una versión para fondo oscuro o claro.
