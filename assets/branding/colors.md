# Paleta de colores — NexoDigital

La paleta está pensada para transmitir tecnología, confianza, claridad, innovación y profesionalismo.

## Colores principales

| Nombre | HEX | Uso recomendado |
|---|---:|---|
| Azul Nexo | `#2563EB` | Color principal, botones, links, isotipo, destacados |
| Cian Digital | `#06B6D4` | Gradientes, acentos, estados activos, detalles tecnológicos |
| Grafito Profundo | `#0B1320` | Fondos oscuros, headers, dashboards, piezas premium |
| Gris UI | `#1E293B` | Textos secundarios, paneles, tarjetas oscuras |
| Gris Claro | `#F3F5F7` | Fondos claros, separadores, áreas neutras |
| Blanco | `#FFFFFF` | Fondos, contraste, versión negativa |

## Gradiente oficial

```css
background: linear-gradient(135deg, #2563EB 0%, #06B6D4 100%);
```

## Recomendación de uso

- Usar el azul como color de confianza y acción.
- Usar el cian como acento tecnológico, nunca como único color dominante.
- Usar grafito para piezas premium, dashboards y presentaciones de alto impacto.
- Mantener mucho espacio blanco para reforzar simpleza y claridad.

## Accesibilidad

Evitar texto pequeño en cian sobre blanco. Para textos principales, priorizar `#0B1320`, `#111827` o blanco sobre fondo oscuro.
